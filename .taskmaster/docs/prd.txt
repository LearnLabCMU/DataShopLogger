DataShop Logger TypeScript SDK

## Overview
Create a modern TypeScript SDK version of the DataShopLogger library that can be published to npm registry. The SDK will provide type-safe interfaces for logging educational data to Carnegie Mellon's DataShop system.

## Goals
- Provide a fully typed TypeScript SDK for DataShop logging
- Ensure backward compatibility with existing JavaScript implementation
- Create a well-documented, easy-to-use npm package
- Include comprehensive unit tests
- Support modern JavaScript environments (Node.js and browsers)

## Requirements

### Core Functionality
- Initialize logging sessions with DataShop credentials
- Log tool messages (student interactions)
- Log tutor messages (system responses)
- Handle hint requests and responses
- Support custom fields on messages
- Manage session state and context
- Support both synchronous and asynchronous operations

### Technical Requirements
- Written in TypeScript with full type definitions
- Support for ES modules and CommonJS
- Compatible with Node.js 14+ and modern browsers
- Zero runtime dependencies (only dev dependencies allowed)
- Comprehensive error handling with custom error types
- Configurable logging levels and debugging options

### Package Structure
- All code in ts-sdk/ directory
- Separate src/ for source code and dist/ for compiled output
- Type definitions automatically generated from TypeScript
- Examples directory with usage samples
- Comprehensive README with API documentation

### Testing Requirements
- Unit tests using Jest with TypeScript support
- Minimum 90% code coverage
- Integration tests for DataShop API interactions
- Mock server for testing without real DataShop instance
- CI/CD ready test configuration

### Documentation Requirements
- Complete API documentation with JSDoc comments
- README with installation, quick start, and examples
- CHANGELOG for version history
- Contributing guidelines
- Type definitions with helpful comments

### Build and Publishing
- Modern build toolchain (ESBuild or Rollup)
- Automated build process
- npm publish configuration
- Semantic versioning
- GitHub Actions for CI/CD

## Deliverables
1. TypeScript SDK in ts-sdk/ directory
2. Comprehensive test suite
3. Full documentation
4. Build and publish configuration
5. Example applications demonstrating usage
